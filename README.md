# Геннадич и Саняра: Нейросетевые приключения

Пиксельный кооп-платформер про Геннадича, Саняру, нейрохрючево и Опоссума-Макса.
Стек как у VinylHead: Phaser 3.90 из `vendor/`, обычные `<script>` без сборки, вся графика —
процедурный пиксель-арт со скелетной анимацией, звук и музыка — синтез WebAudio.

## Запуск

Открыть `index.html` двойным щелчком (Chrome, Firefox, Safari). Сервер не нужен.
Звук включается после первого нажатия клавиши.

## Управление

| | Один игрок | Игрок 1 (кооп) | Игрок 2 (кооп) |
|---|---|---|---|
| Бег | ← → или A D | A D | ← → |
| Прицел вверх / вниз | ↑ ↓ или W S | W S | ↑ ↓ |
| Прыжок | Z, Пробел | G, Пробел | K |
| Огонь | X | F | J |
| Спецприём | C | H | L |
| Суперудар | V | R | U |

Вниз + прыжок — спрыгнуть с полки. Esc / P — пауза, M — звук, F1 — хитбоксы.
Геймпады: A — прыжок, X — огонь, B — спец, Y/RB — супер, Start — пауза.

## Герои

- **Геннадич** — скорострельный код-бластер `</>`, спец «ЩА БЫСТРО ПОФИКСИМ»: рывок с неуязвимостью.
- **Саняра** — пиксель-бластер (держи огонь — заряд), спец «СЕЙЧАС СЕТКУ ПОПРАВИМ»: платформа-сетка и второй прыжок.
- **Юрич** — открывается, если найти 3 золотые кошки или пройти игру. Красный лазер и катана.

## Этапы

1. Посадочная страница — обучение, секретная пещера, спящее хрючево, артефакт.
2. Попап-мегаполис — окна-монстры (бей по [X]), глитч-платформы, Петушня, Клод-мех.
3. Ядро нейросети — босс Опоссум-Макс в три фазы.

На каждом этапе спрятана золотая кошка в сусальном золоте.

## Для разработки

- `index.html?lab` — стенд ригов (все персонажи и клипы, прицел мышью).
- `index.html?level=2` / `?boss` — сразу на этап; `&coop` — вдвоём; `&hero=sanyara`; `&nostory` — без комиксов; `&god` — бессмертие.
- `python3 tools/build_assets.py` — пересобрать картинки из кадров видео в `js/data/images.js` (нужен ImageMagick).

Структура: `js/art` — пиксель-арт и шрифт, `js/rig` — скелетная анимация (кости, IK, пружины, клипы),
`js/entities` — герои, враги, босс, мех, предметы, `js/level` — ASCII-уровни, `js/scenes` — сцены,
`js/audio` — синтез звука и чиптюн-треки, `js/data/lines.js` — все шутки и реплики.
