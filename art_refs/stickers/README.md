# Стикеры — ручная нарезка

Положи сюда PNG с прозрачным фоном, имя файла = ключ стикера (например `ogon.png`).
Такой файл заменяет автонарезку. Берётся как есть, 1:1 в пикселях игры (экран 640×360, старые стикеры ≈150×115).
Пересборка: `python3 tools/build_assets.py`.

`_auto/` — что сейчас нарезано автоматически (для примера и как заготовка). Сборка эту папку не читает.
